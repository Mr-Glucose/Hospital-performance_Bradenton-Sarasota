# Hospital Performance & Readmission Insights — Bradenton / Sarasota

## Overview
This project analyzes publicly available hospital-level data to compare readmission rates, patient experience, and safety metrics for local hospitals:
- Manatee Memorial
- HCA Florida Blake Hospital
- Lakewood Ranch Medical Center
- Sarasota Memorial

## Research Question
How do readmission rates and patient satisfaction differ across these hospitals, and what factors might explain those differences?

## Project Structure
- `/data/raw/` — unprocessed downloaded data  
- `/data/clean/` — cleaned datasets ready for analysis  
- `/notebooks/` — Jupyter or Colab notebooks  
- `/docs/` — charts, reports, communication materials  
- `/reflections/` — personal reflections and milestone notes
